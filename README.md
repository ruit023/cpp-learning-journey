# 🛒 CoopMart Inventory Management System



A CLI-based inventory management system developed in Python during my Matriculation studies at Kolej Matrikulasi Johor (KMJ).

---

### 📖 Project Overview
This Python application was built as part of an assignment to manage daily inventory operations for a cooperative store (CoopMart). It provides an interactive command-line interface (CLI) for users to seamlessly handle store stock.

---

### ✨ Key Features
- ➕ **Add Items**: Add new inventory items with specified quantities or automatically update quantities for existing items.
- 🗑️ **Delete Items**: Remove items from the inventory list.
- 🔍 **Search Quantity**: Search for specific items to check current stock levels.
- 📋 **Display Inventory**: View a complete list of stored items and their quantities.
- 🔤 **Custom Sorting Algorithm**: Includes a built-in sorting function that automatically sorts inventory items alphabetically along with their respective quantities.

---

### 🛠️ Tech Stack & Concepts Used
- **Language**: Python 3
- **Platform**: Google Colab / CLI
- **Concepts**: Custom Functions, Data Structures (Lists & Parallel Lists), String Manipulation (`.lower()`), In-place Sorting Algorithm.
